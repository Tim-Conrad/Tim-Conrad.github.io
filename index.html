CVE-2022-46166 · Dec 2022 · CWE-94

Remote code execution in Spring Boot Admin

The Microsoft Teams notifier read one of its settings as an expression template, and a signed-in user could change it. I reported it in November 2022; the fix and the advisory followed 11 days later.
