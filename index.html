Sheet 2 · Research · CVE-2022-46166

Remote code execution in Spring Boot Admin

The Microsoft Teams notifier read one of its settings as an expression template. A signed-in user could change that setting in the web UI. I reported it in November 2022. The fix and the advisory followed 11 days later.
