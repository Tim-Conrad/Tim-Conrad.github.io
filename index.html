Sheet 2 · Research · CVE-2022-46166

Remote code execution in Spring Boot Admin

The Microsoft Teams notifier read one of its settings as an expression template. A signed-in user could change that setting in the web UI. I reported it in November 2022. The fix and the advisory followed 11 days later.

  1. Enable the notifier

    Teams notifications are switched on.

  2. Change the setting

    Set theme_color to a Java expression.

  3. Trigger a notification

    For example, delete the application.

  4. Code runs on the host

    The server evaluates the expression.

Weakness
CWE-94, code injection
Affected
codecentric/spring-boot-admin, tested on 2.7.7
Needs
A signed-in user and Teams notifications enabled
