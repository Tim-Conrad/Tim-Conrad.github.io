~/research

A theme colour that ran code

Spring Boot Admin read its Microsoft Teams notification settings as expression templates. Any signed-in user could edit those settings from the web UI.

CVE-2022-46166GHSA-w3x5-427h-wfq6CWE-94

Template injection in Spring Boot Admin leads to remote code execution

The notifier parsed theme_color as a Spring Expression Language template. Put an expression there, trigger any notification, and the server evaluates it with full access to Java types. That is arbitrary code on the host.

MicrosoftTeamsNotifier.javathe vulnerable setter
public void setThemeColor(String themeColor) {  this.themeColor = parser.parseExpression(themeColor, ParserContext.TEMPLATE_EXPRESSION);}

Remote code execution

CWE-94, improper control of generation of code
Affected
codecentric/spring-boot-admin, tested on 2.7.7
Needs
An authenticated user and Teams notifications enabled
Fix
SimpleEvaluationContext replaces StandardEvaluationContext in 320eab1
Advisory
GitHub Security Advisory

  1. Enable the notifier

    Run Spring Boot Admin with Microsoft Teams notifications switched on.

  2. Plant the expression

    In the Environment tab, set ms-teams.theme_color to a Java gadget.

  3. Trigger a notification

    Any event will do. Deleting the application is the quickest.

  4. Code runs on the host

    The notifier evaluates the colour as a template, and the gadget executes.
